## New Features

- `WatcherSink` to send traces to [Orkes Watcher](https://github.com/hfahrudin/orkes-watcher), plus `trace_sinks` on `OrkesGraph`. Sinks are called at run start, after each edge and at run end.
- `arun` for running graphs asynchronously.
- Traces now record node-only time, step start time, the failed node and its traceback.

## Updates & Fixes

- Request timeouts for LLM calls, and tracing for streamed calls.
- Default models and parameters updated where current provider APIs rejected the old ones.
- `health_check` uses the `/models` endpoint.
- Clearer error message when `max_passes` is exceeded.
- Run id, trace, counters and edge passes now reset on every run.
- Failed runs and the failing edge are now recorded in traces.
- Snapshots are deep-copied, and function/LLM traces are kept per traversal.
- Lambda gates and postponed annotations are accepted.
- Tool-call round trips: tool call ids are kept, and tool messages are converted correctly for OpenAI and Anthropic.
- Each provider is sent only the message fields it accepts.
- An aggregation node reached without its fork gets empty `branch_results` instead of failing.
- Gemini: `system_instruction` and tool call/result parts are handled correctly.
- All system messages are kept.
- LLM tool tracing, saving traces with non-JSON data, and inspector escaping.
- Docs: "Sending Traces to Watcher" guide, what a trace records, saving traces and `traced=False`.

## Breaking Changes

- **Pydantic removed.** Graph models are now plain dataclasses, and the graph API has no third-party dependencies. Replace `obj.model_dump()` with `to_dict(obj)` (or `to_json(obj)`) from `orkes.shared.schema`. The trace format is unchanged.
- **Aggregation nodes must merge `branch_results` explicitly.** Parallel branch state no longer leaks between branches.
- **Built-in orkes server dashboard removed.** Use [Orkes Watcher](https://github.com/hfahrudin/orkes-watcher) instead. This drops the `fastapi`, `uvicorn`, `click` and `schedule` dependencies.
