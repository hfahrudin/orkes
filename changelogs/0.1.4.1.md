## New Features

- `final_state` on the run trace: a copy of the graph state when the run ended. For a finished run it's the output; for a failed run it's the state at the moment of failure. Edge snapshots show the state *before* each node, so this is the only place the last node's result appears. Available to trace sinks in `on_run_end` and in saved traces.

## Updates & Fixes

- A run's trace status is now `RUNNING` while it's in progress. Before, it read `FAILED` until the run ended, so trace sinks saw `FAILED` in `on_run_start`.
- Docs: `add_parallel_edges` now states that branches run one after another (not concurrently) under both `run()` and `arun()`, with a tip on using `asyncio.gather` inside a node for concurrent calls.
- Docs: the tracing guide covers the `RUNNING` status and `final_state`.
- Roadmap updated: Pilot run control and human feedback (planned), concurrent branch execution (under consideration).
